Bosque de verbos — встановлення як застосунок (PWA)

Найшвидше, локально (Linux/macOS):
  cd bosque_pwa
  python3 -m http.server 8000
Відкрий http://localhost:8000 у Chrome і натисни червону кнопку Install.

Щоб мати застосунок скрізь: завантаж цю папку на будь-який https-хостинг
(GitHub Pages, Netlify Drop, Cloudflare Pages). Файли в корені: index.html,
manifest.webmanifest, sw.js та іконки.

Працює офлайн після першого відкриття. Встановлення пропонують Chrome, Edge
та інші Chromium-браузери; в Firefox і Safari кнопка покаже підказку.
